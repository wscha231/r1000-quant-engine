## Implemented contracts

`tools/research_decision_v1/quality.py` validates a closed claim schema, captured
UTF-8 excerpt hashes/quote matches, source roles and origins, supersession,
time ordering and expiry. A separately supplied receipt binds the exact claims,
source identities and scenario bindings to an explicit model/human review.
Seven axes remain separate: technology, bottleneck, competition, demand
sustainability, governance, management/allocation, price expectations. All six
business axes require reviewed core evidence; absent evidence is not neutral.
A supported critical adverse claim cannot be offset by technology. Price-axis
absence cannot erase a business assessment. Legacy company_quality is ignored.

**Trust boundary:** byte matching authenticates only the retained capture, not a
remote server, the entire filing or semantic truth. A receipt is trusted caller
input, not cryptographic reviewer authentication. Schema/source matching/review
are separate outputs. The current model-authored pilot is not an independent
review. Facts about an issuer's announcement do not prove competitive superiority.
There is no LLM call, automatic grading, score-to-probability conversion or order.

`quality_bridge.py` calls the existing V1 valuation on copies and preserves all
its input blockers. Its four-question output is independently represented:
business analysis is evaluated before V1's price/data early return. Typed explicit
scenario bindings support direction-only records without numbers. Numeric links
must match a separately supplied baseline and the current scenario, interval,
units, currency and period. Probability changes and unbound/double-counted drivers
are rejected. A reviewed assumption range remains an assumption, not a measured
fact. The comparison is a fixed-current-price counterfactual, not a past account.
No binding mutates the supplied numerical scenario or adds an alpha bonus.

This sidecar does **not** connect to portfolio.py/engine.py/operating CLI, clear
readiness flags, supply missing prices/FX/capital, or fabricate ranks/weights.
`portfolio_proposal_ready=false` remains until the separately reviewed integration
and upstream cash/FX/source-verification issues are addressed. A nested valuation
calculation is not a ready portfolio. Existing PE/EV_EBITDA/profitable-company and
12-month limits remain; no artificial 1/3/6-month projections are introduced.

`quality_index.py` provides pure compare-and-swap/self-hashed index transitions.
Reviewed snapshots, latest execution (including failure) and latest successful
execution are separate. REAL/SYNTHETIC pointers cannot replace one another.
The event source_sha identifies execution code; artifact paths resolve relative
to the **commit containing the index**, not necessarily that earlier code commit.
Storage authorization, actual referenced-byte verification and reviewer identity
are consumer responsibilities. The index is not an operating account registry.

## Real pilot and replay

`research/decision_v1/quality_evidence_20260909/pilot_capture.json` retains bounded
primary-source captures, transport limitations, seven open questions per company
and model review receipts. Printed publication dates are not invented as exact
timestamps: available_from is conservatively the current observation. Current
capture hashes must not be described as historical PIT or full HTTP-body hashes.

Run from an inspected full checkout with its dependency at the pin above:

```sh
python -I tests/research_quality_v1_smoke.py
python -I -O tests/research_quality_v1_smoke.py
python -I research/decision_v1/run_quality_pilot.py --input research/decision_v1/quality_evidence_20260909/pilot_capture.json --output-dir /tmp/quality-pilot-new-directory --source-sha CODE_COMMIT_SHA
```

The replay requires a new output directory, reads no provider and deliberately
exits 2 for investment-blocked partial analysis. Its source_sha is a caller label;
per-file hashes describe the actual local files. It is not the secure H1 export
or original isolated Git-verification launcher. Review receipts are retained
input, not silently regenerated by the runtime. No existing operating writer is
used. Inspect both repeat-result equality and source file hashes.

The real capture covers NVDA/EME/KR:000660 announcements only, including an EME
comparison candidate. None completes a company-wide core-axis review. Actual H1
market admission, normalized TTM, official prices/actions/benchmarks, complete
scenarios, FX, risk and funding remain unmaterialized in this slice. No real
stock is recommended; missing evidence is not a negative company judgment.
