## Publishing source: GitHub Actions (NOT "Deploy from a branch")

GitHub Pages' "Deploy from a branch" UI only allows the repository root (`/`)
or `/docs` as the source folder — **a nested folder like `/docs/public/` is
not selectable**. Selecting `/docs` would publish every internal strategy doc
under `docs/` (CODEX_*, MASTER_PRIORITY_*, SYSTEM_INTEGRATION_*, …), which we
do not want.

Instead this repo uses the **GitHub Actions deployment path**
(`.github/workflows/pages_deploy.yml`), which uploads **only `docs/public/`**
as the Pages artifact. The rest of `docs/` is never published.

### Activation (user-side, one-time, ~3 minutes)

1. Visit `https://github.com/wscha231/r1000-quant-engine/settings/pages`
2. Build and deployment → **Source: `GitHub Actions`**
   (do NOT pick "Deploy from a branch")
3. The `Deploy GitHub Pages (docs/public)` workflow then runs automatically
   on the next push to `docs/public/`, or trigger it once manually from the
   Actions tab (workflow_dispatch).
4. After the workflow's `deploy` job completes, the site is live at
   `https://wscha231.github.io/r1000-quant-engine/`

## Privacy note — read before activating

**Publishing is PUBLIC unless you have GitHub Enterprise Cloud.** Privately
published Pages (visible only to repo members) require a **GitHub Enterprise
Cloud organization** — a personal account, including **GitHub Pro**, can only
publish Pages **publicly**. (See GitHub's plan docs:
https://docs.github.com/get-started/learning-about-github/githubs-products)

Practical implication:
- On this personal/private repo, activating Pages will make
  `https://wscha231.github.io/r1000-quant-engine/` **publicly reachable**.
- Only `docs/public/` is exposed — currently just the placeholder. The rest of
  the repo (code, internal strategy docs) stays private.
- The real 7-year report only appears here after the W5 + AUTO pipeline ships;
  review its content before that first publish.

**Recommendation:** keep only the placeholder public until Stage 3 (PIT
universe) completes and the credibility baseline is established per
`docs/MASTER_PRIORITY_ROADMAP_20260619.md`. If even a public placeholder is
unacceptable, defer activation, or move publishing to a separate dedicated
public repo (e.g. `r1000-public-report`) so this repo never gains a public
surface.
