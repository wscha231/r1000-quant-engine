1. Visit `https://github.com/wscha231/r1000-quant-engine/settings/pages`
2. Build and deployment:
   - Source: **Deploy from a branch**
   - Branch: **master**

3. Click **Save**

## Privacy note

If the repository is private and you want the Pages site private as well,
GitHub Pro or higher is required (Settings → Pages → Visibility → Private).
Otherwise, activating Pages publishes the placeholder publicly until
auto-publish ships the real report.

Recommendation: activate now in private mode (if available) so the pipeline
can be wired and tested; flip to public after Stage 3 credibility baseline
is established.
