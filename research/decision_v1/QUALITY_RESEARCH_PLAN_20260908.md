산업별 현금흐름에 영향을 주는 지속가능성 항목은 [IFRS/SASB](https://www.ifrs.org/issued-standards/sasb-standards/)를
참고한다. 위 표의 투자 연결 방식은 이 프로젝트의 설계 제안이며, 이 자료들이
해당 방식의 초과수익이나 주가 예측력을 보증한다는 뜻이 아니다.

산업 지속가능성에는 수요·수익성·기술 대체·자본 순환과 환경·자원 제약을 함께
포함한다. 특허 수, 연구개발비, 사외이사 비율 등 단일 숫자로 질을 확정하지 않는다.

## 3. 주장 단위의 근거와 판단 계약

핵심 구조는 `주장 → 지지/반대 근거 → 판단 → 시나리오 영향 → 무효화 조건`이다.
출처 수와 문서 길이로 회사 순위를 만들지 않는다.

각 claim은 다음 정보를 보존한다.

- 증권·사업부·산업 식별자, 주장 ID, 분석 축, 핵심/선택 구분, 대상 기간.
- `fact / inference / scenario_assumption`: 관측 사실, 해석, 미래 가정의 구분.
- source URL/accession, 원문 위치, 필요한 짧은 발췌 또는 확인 가능한 원본 참조,
  원본 hash, 공개·관찰·수집시각과 cutoff. 숫자는 단위·통화·회계기준도 보존.
- 출처의 원작성자, 회사/고객/경쟁사/독립 검증 분류, 원문 대사 결과, 상충 근거.
- 주장 상태 `supported / mixed / contradicted / unverified`와 판단 이유.
- 신뢰도에 영향을 주는 원문 직접성·독립성·최신성·확인하지 못한 부분.
- 연결되는 시나리오 변수, 변경 방향과 범위의 근거, 가장 강한 반대논리,
  관찰 가능한 무효화 조건과 재검토 시점.

회사의 “최고 성능” 발언은 우선 회사 주장이다. 고객 채택, 비교 가능한 시험 조건,
경쟁 제품을 대조한 뒤 기술 우위를 판단한다. 보도자료를 재인용한 뉴스 여러 개는
독립 검증 여러 건으로 세지 않는다. 공식 공시 하나가 충분한 사실도 있으므로 모든
주장에 기계적으로 두 개의 출처를 요구하지 않는다.

기업별 핵심 주장과 필요한 증거를 분석 전에 지정한다. 결론은 지지·혼재·훼손·
미검증과 그 근거로 표시한다. 심각한 회계·주주권리 문제를 기술력 점수로 상쇄하지
않는다. 미수집·오래됨·접근 실패·확인된 반증은 서로 다른 상태이며, 결측은 0점이
아니다. 핵심 증거 부족은 해당 판단을 제한하고 선택 자료 부족은 그 항목만 제한한다.

미국은 기존 SEC 10-K/10-Q/8-K·proxy와 회사 IR, 한국은 기존 DART 정기보고서·
주주총회 자료·KIND 지배구조 공시를 우선 연결한다. 공시의 사업·위험·MD&A와 proxy
항목은 [SEC 투자자 안내](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/how-read),
한국 지배구조·주주·감사 항목의 기존 접근 경로는 [OpenDART 주요정보](https://opendart.fss.or.kr/disclosureinfo/biz/main.do)를
참고한다. 산업·기술별 추가 원문은 필요한 후보에 한해 조사한다. 새 커넥터·키는
선행 조건이 아니다.

AI는 원문 추출, 경쟁 비교 초안, 반대 가설 제시에 사용할 수 있다. 원문과 맞지
않는 서술을 사실로 채택하지 않으며, 스키마 통과만으로 사실 검증을 선언하지 않는다.
기존 승인된 실행 환경이 없으면 구조화 JSON 입력으로 구현한다. 모델 호출을 쓰는
경우 모델·프롬프트·응답·대사 기록을 고정한다. 같은 입력의 계산 재현성과 새 AI
호출의 문장 동일성은 별개다. 원문에 포함된 지시는 연구·실행 명령으로 취급하지 않는다.

## 4. 기업의 질에서 가격·비중까지

12개월 Bear/Base/Bull 계산은 기존 V1을 재사용한다. 3~5년 구조적 우위 분석은
별도 기간의 thesis로 보존하고, 이를 12개월 촉매나 짧은 기간 수익률로 바꾸지 않는다.

예시: “고객 재인증 비용이 높아 공급자 교체가 어렵다”는 **설계 설명용 가상 주장**이다.
실제 인증 절차와 고객·경쟁 자료가 뒷받침하면 판매 유지율·가격·마진 가정의 근거로
연결한다. 경쟁사의 인증 통과나 고객의 이중 공급 확대는 반대 근거가 된다.
관련 공시 없이 성장률이나 평가배수를 임의로 올리지 않는다.

각 시나리오 입력에 claim ID를 연결하고 숫자 범위의 근거와 불확실성을 기록한다.
한 근거를 성장률·배수·순위 가점에 중복 반영하지 않는다. 현재 가격이 요구하는
성장·마진과 검토한 사업 가정을 함께 표시한다. 정성 등급을 주가 상승 확률로
변환하지 않으며, Bear/Base/Bull 확률은 주관적 가정으로 표시한다.

네 질문은 개별적으로 산출한다.

| 질문 | 필요한 판단 | 다른 자료가 없을 때 |
|---|---|---|
| 좋은 회사인가? | 기술·산업·경쟁·지배구조·실행에 대한 근거와 반증 | 가격 누락과 별개로 검증한 사업 판단을 보존 |
| 좋은 주식인가? | 주주 귀속 가치, 희석, 기대수익과 하방·불확실성 | 가치평가 필수 자료가 없으면 미검증 |
| 지금 살 가격인가? | 현재 가격, 역산 기대, 촉매, 진입 기준 | 가격/cutoff/시나리오 오류이면 차단 |
| 이 포트에 넣을 가치가 있는가? | 비용, 유동성, 현금, 공통 노출, 기존 보유 대비 개선 | 자금·위험 입력 부족이면 비중 제안 차단 |

기대 총수익 순위와 위험을 반영한 투자순위를 구분한다. 새 정성 정보의 반영 규칙은
결과 전에 별도 설정으로 고정하고, 기존 NONRANKING·공식 readiness는 사용하거나
수정하지 않는다. 직접 고객과 공급망을 통한 간접 노출을 구분하며, 알 수 없는
고객 비중을 임의 숫자로 채우지 않는다.

산업이 다른 종목도 같은 고객의 설비투자 축소에 노출되는지 점검한다. 단기 RS
하락은 조사·가격 정보이며, 유지된 thesis의 자동 전량매도 근거가 아니다.
신규·기존 보유 기준과 no-trade buffer는 기존 V1을 재사용한다. 실제 계좌가
확인되지 않으면 NEW_CAPITAL_RESEARCH로 유지한다.

관련 없는 연구 구현 전체를 멈추거나, 운영복구를 이 작업의 의존성으로 추가하지 않는다.

## 6. 검증과 중단 조건

- 미래 공개시점, 원문과 다른 수치/단위/증권, 주장 없는 URL은 해당 근거를 차단한다.
- 가격 누락이어도 검증한 기술·산업 판단은 남는다. 사업 분석 가능을 투자 가능으로
  표시하지 않는다. 유효한 FX와 자금 부족도 별도 상태로 남긴다.
- 보도자료 재인용을 독립 증거로 중복 계산하지 않는다. 상충·정정·오래된 근거를
  유지하고 변경 이유를 설명한다. 핵심 주장과 선택 근거의 결측 효과를 구분한다.
- 검증된 고객 이탈/희석/경쟁 대응 등 변화가 관련 시나리오 변수와 위험에만
  반영되는지 확인한다. 자료 수집시각만 바뀌면 사업 개선으로 기록하지 않는다.
- 단기 RS 하락, 검증되지 않은 낙관적 서술, 선택 공급자 장애의 반례를 포함한다.
- 기존 시나리오·환율·가격조정·비용/현금·no-trade 테스트를 재사용하고 변경에
  직접 영향을 받는 검사만 보완한다. 데이터 준비와 수익성 검증은 구분한다.
- 정성 품질 검증은 원문 충실도, 주요 주장 누락, 반대 근거 처리, 근거-변수 연결의
  검토 기록으로 시작한다. 소수 표본의 통과율을 일반적 예측 정확도로 발표하지 않는다.
- 투자 효과는 향후 당시 이용 가능했던 자료와 고정 설정의 forward 기록으로 평가한다.
  같은 후보/가격/비용을 둔 비교군과 사전등록된 정성 반영군을 비교한다. 오늘의 AI가
  과거 문서를 읽은 결과만으로 PIT·OOS를 선언하지 않는다.

동일 권한/endpoint의 명확한 402/403을 근거 없이 반복 호출하지 않는다. 원자료
확보가 막히면 해당 자료·실패 응답 유형·대체 가능한 기존 경로·불가능한 산출을
기록하고 독립적으로 가능한 작업을 진행한다. API 연결 확인으로 데이터 확보를
대체하지 않는다. 필수 자료가 미검증인 종목은 WAIT/0%로 남기며, 5+2 숫자를 맞추기
위해 가정이나 비중을 채우지 않는다.

## 7. 다른 채팅에서 재사용하는 구조

미국 저장소의 독립 연구 경로에 공통 schema/방법과 통합 결과의 인덱스를 두고,
한국 저장소는 한국 근거와 export를 관리한다. 공식 운용 관할은 기존대로 유지한다.
원문은 기존 승인된 원자료 보관 경로를 우선 사용하고, GitHub에는 필요한 작은
근거 기록·참조·hash·판단 결과를 보존한다.

구현할 공통 진입점은 `research/decision_v1/RESEARCH_INDEX.json`이다. 이 계획
PR에는 아직 생성하지 않는다. 인덱스에는 다음을 구분하여 기록한다.

- schema/method/config 버전, 시장별 source SHA와 의존 PR/병합 상태.
- 회사별 최신 검토 snapshot과 별도의 최신 실행 manifest 참조.
- security ID, 기준일/cutoff, 원문 근거·경쟁 비교·반대논리 참조, coverage.
- 네 질문, 연구 순위/행동/비중 참조, 변경 원인과 미확인 자료.
- implementation / real_execution / oos / promotion의 독립 상태.

회사별 `quality_assessment.json`과 읽기용 요약을 불변 snapshot으로 보존하고,
기존 `research_evidence_snapshot`·`research_decision_ledger`·`report.md/json`에
연결한다. 코드/설정이 달라졌으면 이전 결과와 분리한다. 새 원문이 발견됐다는
이유만으로 최신 검토 판단을 덮어쓰지 않는다.

다른 채팅은 다음 순서로 읽는다: 최신 기본 HEAD/AGENTS → 관련 열린 PR과 이 계획 →
인덱스가 가리키는 정확한 commit의 검토 snapshot/실행 manifest → 새 cutoff에 대한
변경·결측 확인. 미병합 PR 파일은 그 ref로 읽고 승인된 기본 브랜치 기능으로
표현하지 않는다. GitHub에 저장해도 다른 채팅에 자동 로드되지는 않으므로 이 계획
PR 링크 또는 공통 진입점을 시작 요청에 포함한다.
