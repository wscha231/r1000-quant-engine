## 실제 데이터 복구에서 확인한 것

- GitHub 공식 run 28725350727의 artifact 8088582521은 메타데이터상 369,243,166 bytes, 만료되지 않음, SHA-256 ebdbbe7e764b735ca129f662c42ec80b68659f4e3196b5a364cf32c506c4c818. 다운로드 전송이 HTTP 403으로 실패했다. 실제 ZIP bytes/hash는 검증하지 못했다.
- 기존 로컬 캐시 두 곳은 manifest만 있다. 하나는 2016-01-04~2026-09-04, 80종목을 주장하고, 다른 하나는 2026-07-01~2026-09-08, 97종목을 주장한다. 실제 parquet 파일은 해당 로컬 폴더에 0개였다. manifest의 날짜·종목 수를 가격 검증으로 인정하지 않는다.
- Google Drive 프로젝트의 cache_prices를 직접 열어 첫 100개 항목 중 manifest 1개·parquet 99개를 확인했다. 목록은 100개 제한으로 부분일 수 있다. reports에는 candidate_replay_book.csv 63,428,475 bytes도 있다. 이름만으로 공식 run과 동일한 파일이라고 인정하지 않는다.
- Drive에서 인증된 파일 참조는 반환됐으나, JSON 원본을 이 환경으로 받는 단계도 HTTP 403이었다. parquet 본문은 검사하지 못했다. 소스가 없다고 단정하지 않고, 원본을 읽을 수 있는 실행환경에서 복구·해시·기간·커버리지를 검증해야 한다.

1. **종목/가격:** 당시 투자 가능 종목군, 상장폐지·합병·분할·배당·티커 변경, 실제 체결일, 거래정지, 한국 거래일/통화/벤치마크. 현재 생존 종목으로 과거를 채우면 생존편향이 생긴다.
2. **숫자:** 당시 공시 접수 시각의 재무, 주식수·순부채·FCF, 당시 사용 가능 예상치와 12개월 Bear/Base/Bull 가정. 오늘의 재작성 재무나 예상치를 과거에 붙이지 않는다.
3. **퀄리티:** 산업·기술·해자·경쟁/대체·경영/자본배분·지배구조·지속가능성의 주장, 원문, 반대근거, 최초 가용시각, 검토 상태와 가정 변경 이력. 발행일이 오래됐다는 이유만으로 오늘 수집/판단한 자료를 당시 알려진 판단으로 만들지 않는다.
4. **현재 실제 표본:** 기존 NVDA·EME·SK하이닉스 부분 캡처는 3개 기업의 현재 연결 검증이다. 과거 결과에 기록된 새 검토 승인 0개·필수 투자 입력 0/3을 해소하지 않으며, 7~8년 종목군/품질 이력이 아니다.
5. **검증 구분:** 재구성한 과거 문서 분석은 RETROSPECTIVE_RECONSTRUCTION으로 따로 표시한다. PIT를 통과한 반복 시점 외부검증이나 이미 동결된 당시 판단을 대체하지 못한다. 새 정성 판단은 실제 시점부터 forward 연구 이력을 쌓을 수 있다.
